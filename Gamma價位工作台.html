03 自動選線
這些設定如何選線？

先限制價格範圍，再按正負各自的 |Gamma| 排名；只取達到強度門檻、符合間距的前幾名。

最低強度：同週同向最大柱為 100%。例如 100、40、15，門檻 20% 會留下 100 和 40。

價格範圍：快照現價 200、±30% 時，候選價位為 140–260。設 0 為全部；改變範圍也可能改變排名與強度分母。

最小間距：以價格金額計算，只限制同向價位。例 200、202.5、205，若 200 最強且間距設 5，可保留 200、205。預設 0 保留相近大價位。

預設：正負各 3、強度 20%、範圍 ±30%、間距 0。只影響自動 Gamma 線；手動線與 Table CE 不受篩選限制。

恢復預設會清除手動線與隱藏狀態，重建自動線與 Table CE；保留已匯入資料、CE 取值方式及結算範圍。

選線邏輯與資料來源

僅讀取 HTML 中按到期日命名的 Plotly 長條資料（Gamma / GEX），不執行上傳檔案的 JavaScript。相同週、相同履約價先做帶正負號的加總，再依正負各自排序；跨到期日方向相反的 Gamma 會互相抵銷。

本工具以長條的 |Gamma| 判定「量大」，並非選擇權成交量 Volume。資料當週只代表 HTML 中仍存在的到期日，無法補回已結算的週一至週四資料。每個 HTML 是獨立快照，一次處理一份資料，不跨檔相加。

Gamma Flip、Gamma Field、Call / Put Wall 等 Level 價位一律以 Lieta Table 為準。黃色 CE 線取該週最後到期日的 Gamma_Flip，不把 CE 加總或平均；缺值留白。其他 Level 可在下方原始價位表核對。預覽是價位示意，不包含 K 線或即時行情。

匯出的 Pine 指標是靜態快照。每次更新 HTML 後重新匯出；未提供歷史當日可得資料，因此不適合作為無前視偏差的回測訊號。

新增價位線
TRADINGVIEW EXPORT

你的價位，準備上圖。

在 TradingView 開啟「Pine 編輯器」，建立新指標，貼上後選擇「新增到圖表」。

線條以美東週一至週五定位，包含夏令時間。預設畫到週五開盤，讓週與週之間留白；在指標設定關閉「週間留白」可畫到週五收盤。Pine 線條需回到本工具調整，不是 TradingView 原生可拖曳繪圖。新增指標後若看不到未來週，請將圖表向左拖出右側空間。

從 HTML 到 TradingView

  1. 載入 一份 Lieta Gamma HTML。新 Gamma 會取代目前資料，清除舊 Table 與手動線，恢復預設篩選。
  2. 選結算範圍，同週多個到期日會合併。週數以曆週計算，不會把缺少到期資料的週補成有資料。
  3. 觀察分布：切換整週／單一到期日，或查看全部履約價，不影響已選線。觀察價位可查看各到期日貢獻；實際加入仍採整週淨 Gamma。
  4. 微調價位：點 Gamma 長條挑選、拖曳預覽線或直接輸入價格。改動自動篩選會更新自動線，手動線保留。
  5. 設定黃線：在 Lieta 選 Table → 輸入相同股票 → Enter → 下載，再點選或拖入「載入 Table HTML」，核對後套用。每週取最後到期日的 Gamma_Flip。
  6. 匯出 Pine Script，貼入 TradingView 新指標並新增到圖表。資料更新時重新匯出。

「儲存工作檔」會保留資料、篩選與手動線。下次用「載入 Gamma HTML」選取該 JSON，即可恢復原有設定與觀察位置。重新整理頁面會回到空白狀態。
